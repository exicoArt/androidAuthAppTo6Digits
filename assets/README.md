# Assets

## Tulou-lamp.glb

Openwork-lattice table lamp shaped like a circular tulou (Fujian earthen roundhouse), produced through parametric modeling scripts that output ready-to-print files.

- Three concentric rings of openwork upright-rod lattice walls, a tapering ring roof and an arched doorway.
- A charcoal round base with a deck, battery retainer and removable maintenance cover.
- Inside the walls, a ring of citrine translucent diffuser segments and reflectors surrounds a warm-white LED ring, so light glows evenly through the lattice.
- Palette: bone white, charcoal and amber.

File facts: glTF 2.0 binary, about 14.3 MB, 18 meshes, about 330k triangles, exported from Blender. The file carries no materials, so viewers show it in default shading.

Used by the [warning landing page](../trap/index.html).
