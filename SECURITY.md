# Security policy

This repository contains educational documentation only. It has no running service and stores no user data.

## Reporting a problem

If you find incorrect or unsafe advice in this guide, open an issue or contact the maintainer at the email listed on the GitHub profile.

**Never include real secrets in a report:** no QR codes, setup keys, backup codes, passwords, recovery phrases or account numbers. If you posted one by accident, treat it as compromised and replace it.
